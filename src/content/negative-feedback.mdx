<section id="intuition">

<div className="section-heading"><span>01</span><h2>The error is the input</h2></div>

Imagine trying to hold a room at 25 °C by fixing the heater at one power level. It might work on one day. Opening a window changes the heat loss and the same command now gives a different temperature. Feedback instead measures the result and changes the command when the result differs from the target.

An amplifier can do the same thing. Rather than asking an uncertain transistor stage to produce an exact output for a given input, compare a measured fraction of its output with the desired input. Apply the remaining **error** to the high-gain stage.

If output rises too far, the returned signal rises, the error falls, and the amplifier reduces its output. That is negative feedback. It is defined by the direction of the corrective response around the complete loop, not by whether a resistor connects to a terminal named “negative.”

<FeedbackBlock />

Use x for input, y for output, A for forward gain, and **b** for feedback factor. We deliberately use b instead of $\beta$ to avoid confusing feedback factor with transistor current gain $\beta$. The error is e = x − by, and the forward amplifier responds to e, not directly to x.

**A useful thought experiment.** Suppose the intended gain is ten, so b = 0.1. If output is 1 V, feedback returns 0.1 V. With a 0.1 V input, this sounds perfect—but then the error would be zero, and a finite-gain amplifier would produce zero output. The actual error must remain slightly positive. High gain makes that required error small; it does not make it identically zero.

The output energy comes from the amplifier's power supply. The input and feedback tell the amplifier how to use that energy. Feeding back a signal does not create power or remove the need for output-current capability.

</section>

<section id="equations">

<div className="section-heading"><span>02</span><h2>Derive the closed-loop equations</h2></div>

Start with the two defining equations and substitute the comparator output into the amplifier equation:

<Equation tex="e=x-by,\qquad y=Ae=A(x-by)" />

Collect every term involving y on the left:

<Equation tex="y+Aby=Ax\quad\Rightarrow\quad G=\frac{y}{x}=\frac{A}{1+Ab}" />

Define **loop gain** T = Ab. The subtraction is already explicit in e = x − by, so T is positive at DC for this noninverting forward block. Some texts include a minus sign in their definition of loop transmission; do not mix conventions.

<Equation tex="G=\frac{1}{b}\frac{T}{1+T},\qquad \frac{e}{x}=\frac{1}{1+T}" />

Only when |T| is large and the loop behaves appropriately can G ≈ 1/b. The precise low-frequency fractional shortfall from 1/b is 1/(1 + T).

**Worked example: finite gain.** A = 1000 and b = 0.1 give T = 100 and G = 1000/101 = 9.90099. With x = 100 mV, output is 0.990099 V, feedback is 99.0099 mV, and error is 0.990099 mV. Multiplying that error by 1000 reconstructs the output.

### Gain sensitivity is a derivative

How strongly does G change when A changes, holding b constant? Differentiate, then normalize by G/A:

<Equation tex="\frac{\partial G}{\partial A}=\frac{1}{(1+Ab)^2},\qquad \frac{dG/G}{dA/A}=\frac{1}{1+T}" />

Thus a small 10% change in A produces about 0.099% change in G when T = 100. This is a **local sensitivity**, not an exact formula for arbitrarily large changes.

If A falls all the way from 1000 to 500, the exact gain changes from 9.90099 to 9.80392: about −0.9804%. Recalculate large changes instead of multiplying the original derivative by −50%.

The feedback network becomes the accuracy-setting element. At large loop gain, G ≈ 1/b, so a 1% fractional error in b produces approximately −1% fractional gain error. Feedback trades dependence on an uncertain forward amplifier for dependence on the sensing network.

### Where a disturbance enters matters

Add a disturbance d directly at the output, inside the feedback pickup:

<Equation tex="y=A(x-by)+d=\frac{A}{1+T}x+\frac{1}{1+T}d" />

An output disturbance is reduced by the **sensitivity function** S = 1/(1 + T). The sensed response to the command is by/x = T/(1 + T), often called complementary sensitivity. Their sum is one.

If instead measurement noise n is added to the returned signal, e = x − by − n, its contribution is −A n/(1 + T). At large T, output follows approximately −n/b. Feedback cannot distinguish a true measurement change from measurement noise. Similarly, errors added before the forward amplifier are generally amplified with the signal; “feedback removes all noise” is false.

### Turn an accuracy target into a loop-gain requirement

The target at infinite loop gain is $1/b$. Divide the exact gain by that target:

<Equation tex="\frac{G}{1/b}=\frac{T}{1+T},\qquad \varepsilon_G=\frac{1}{1+T},\qquad T\ge\frac{1}{\varepsilon_G}-1"/>

A 1% shortfall requires $T\ge99$. At $b=0.1$, the minimum forward gain is 990. A 0.1% requirement needs T at least 999. Apply this at the specified frequency and operating condition, rather than substituting only the largest DC gain.

The same denominator reduces an output disturbance, but the sensing network still defines the target. A 1% feedback-ratio error cannot be corrected by making A arbitrarily large. Separate the finite-gain budget from reference, divider and measurement errors.

</section>

<section id="effects">

<div className="section-heading"><span>03</span><h2>What feedback changes</h2></div>

<LoopAccuracyFigure/>

Feedback usually spends available gain to improve predictability. Its benefits depend on topology, frequency, and remaining actuator range.

**Linearity.** If a forward amplifier's gain changes slightly with signal level, feedback reduces the resulting closed-loop gain variation while loop gain remains large. For distortion generated within a loop, suppression is governed by loop gain at the distortion frequencies. A second harmonic sees the loop at twice the fundamental frequency. The familiar factor 1 + T is an approximation about an operating point, not a promise to repair clipping.

**Output impedance.** For voltage feedback, let an output load current cause an open-loop voltage drop $r_o$ $i_L$. Then:

<Equation tex="y=A(x-by)-r_o i_L" />

Collect the $y$ terms: $y(1 + Ab) = Ax - r_oi_L$, so

<Equation tex="y=\frac{A}{1+T}\,x-\frac{r_o}{1+T}\,i_L\quad\Rightarrow\quad r_{o,\mathrm{closed}}=-\frac{\partial y}{\partial i_L}=\frac{r_o}{1+T}" />

The load current still causes the same internal drop, but the drop appears in the fed-back signal, increases the error, and the forward gain drives the output back up by all but $1/(1+T)$ of it.

This derivation assumes the feedback senses the actual output and the stage can supply the correcting current. A current-limited output cannot maintain this low impedance.

**Input impedance.** With series voltage comparison, the small input error can mean less input current for a given applied voltage, increasing input impedance. Quantify it for a forward amplifier with input resistance $r_i$: the input current is set by the error voltage across $r_i$, $i_{in} = e/r_i$. From the loop equations, $e = x/(1+T)$, so $i_{in} = x/[(1+T)r_i]$ and the source sees $R_{in} = x/i_{in} = r_i(1+T)$. Shunt current comparison instead tends to reduce input impedance. Current sensing at the output tends to increase output resistance. Do not apply “feedback raises input impedance and lowers output impedance” to every feedback circuit.

| Input comparison / output sensing | Common description | Input resistance tendency | Output resistance tendency |
| --- | --- | --- | --- |
| Series voltage / output voltage | Voltage amplifier | Increases | Decreases |
| Shunt current / output voltage | Transresistance amplifier | Decreases | Decreases |
| Series voltage / output current | Transconductance amplifier | Increases | Increases |
| Shunt current / output current | Current amplifier | Decreases | Increases |

These tendencies refer to an appropriately defined loaded forward circuit. A feedback network can itself load input and output; an unloaded textbook A and an arbitrarily chosen b may not reproduce the real circuit.

**Limits.** Feedback cannot supply missing voltage headroom, remove resistor thermal noise, make a slow device respond infinitely fast, or recover a saturated transistor instantaneously. Once the correcting element reaches a rail, the linear equation is no longer the whole story.



<h3 id="book-notes">Sampling and mixing predict which impedances feedback changes</h3>

Feedback can be classified by the output quantity measured and the way the correction is combined with the input. **Voltage sampling** measures across the output; **current sampling** measures in series with the load. **Series mixing** compares an input voltage difference; **shunt mixing** subtracts currents at an input node.

<div className="table-wrap"><table><thead><tr><th>Input mixing</th><th>Output sampling</th><th>Natural closed-loop function</th><th>Ideal impedance trend</th></tr></thead><tbody><tr><td>Series</td><td>Voltage</td><td>Voltage amplifier</td><td>Input rises, output falls</td></tr><tr><td>Shunt</td><td>Voltage</td><td>Transimpedance amplifier</td><td>Input falls, output falls</td></tr><tr><td>Series</td><td>Current</td><td>Transconductance amplifier</td><td>Input rises, output rises</td></tr><tr><td>Shunt</td><td>Current</td><td>Current amplifier</td><td>Input falls, output rises</td></tr></tbody></table></div>

For a simple isolated series-voltage loop, a return ratio T multiplies input resistance by $1+T$ and divides output resistance by $1+T$. With 10 kΩ and 1 kΩ open-loop resistances and T = 99, the corresponding closed-loop estimates are 1 MΩ and 10 Ω. These transformations concern the appropriate driving-point impedances with other independent sources deactivated; feedback-network loading can alter the underlying values.

The inverting op-amp's summing node illustrates shunt mixing: feedback reduces that node's impedance, while a source outside the circuit still sees its input resistor. The current servo illustrates current sampling: feedback raises the output resistance seen by its load. “Feedback lowers output impedance” is true for a voltage-controlled output, not for every useful loop.

<section id="bandwidth">

<div className="section-heading"><span>05</span><h2>Bandwidth and stability</h2></div>

So far A and b were real constants. A real amplifier contains capacitors and transit-time effects; its forward gain A(s) changes magnitude and phase. The same algebra gives:

<Equation tex="G(s)=\frac{A(s)}{1+A(s)b(s)}" />

For one forward pole and constant feedback, A(s) = $A_0$/(1 + s/$\omega_p$). Substitute, then multiply numerator and denominator by $1 + s/\omega_p$:

<Equation tex="G(s)=\frac{A_0}{1+s/\omega_p+A_0b}=\frac{A_0}{(1+A_0b)\left[1+\dfrac{s}{\omega_p(1+A_0b)}\right]}" />

Separate the constant factor from the frequency-dependent one:

<Equation tex="G(s)=\frac{A_0}{1+A_0b}\frac{1}{1+s/[\omega_p(1+A_0b)]}" />

The DC gain falls by 1 + $T_0$, while the closed-loop pole frequency rises by the same factor. This explains gain–bandwidth trading for a single-pole model.

**Example.** $A_0$ = 1000, $f_p$ = 100 Hz and b = 0.1 give DC gain 9.901 and bandwidth 10.1 kHz. The product is 100 kHz. The original gain–bandwidth product is also 1000 × 100 Hz. This equality depends on the model; it is not universal for multistage amplifiers, slew limiting or nonlinear large signals.

More poles add phase lag. A correction intended to oppose an error may arrive so late that it reinforces the motion. Closing a loop can move poles into the right half of the s-plane even though every forward-amplifier pole was originally stable.

</section>

<section id="stability">

<div className="section-heading"><span>06</span><h2>Follow the loop around</h2></div>

The critical denominator is 1 + T(s). At a frequency where T(jω) is near −1—magnitude one and phase −180°—a small disturbance may be strongly reinforced.

For a conventional stable open-loop system with a single unity-magnitude crossover, **phase margin** is 180° plus loop phase at that crossover. A positive margin indicates distance from the critical phase condition; near-zero margin often accompanies peaking and ringing. General systems with multiple crossings, delay or open-loop unstable poles require a full Nyquist or pole analysis.

<LoopStabilityLab client:load />

Lower the second pole or raise the feedback fraction. Both can reduce phase margin in this example. More feedback at DC is not automatically better at every frequency.

A useful physical check precedes any algebra: perturb output upward, follow the sign of every stage and sensing path, and confirm that the resulting drive tries to lower it. Then analyze dynamics. Correct DC polarity is necessary but insufficient.

Dominant-pole compensation deliberately reduces loop gain before extra phase lag accumulates. Its cost is bandwidth. Do not compensate by placing an arbitrary large capacitor somewhere in a feedback network; it can add a pole in the wrong place, alter noise gain, or destabilize a loaded stage.

Measurement also requires care: breaking a DC feedback path can destroy the bias point. Loop-gain injection preserves the intended operating point and loading. See [Analog Devices' loop-gain discussion](https://www.analog.com/en/resources/technical-articles/loop-gain-and-its-effect-on-analog-control-systems.html) for the connection between loop behavior and control systems. The next chapter finds these same relationships inside transistor circuits.

</section>

<details>
<summary>1. What signal does the forward amplifier amplify?</summary>
<div>

The difference between command and returned measurement, not the entire command without regard to output.

</div>
</details>

<details>
<summary>2. What loop gain gives at most 1% static gain shortfall?</summary>
<div>

$T\ge99$ for the stated ideal model.

</div>
</details>

<details>
<summary>3. Is measurement noise rejected like an output disturbance?</summary>
<div>

No. Noise in the returned measurement is interpreted as an output error, so the controller moves output in response.

</div>
</details>

<details>
<summary>4. Does correct DC feedback polarity guarantee stability?</summary>
<div>

No. The frequency-dependent loop must also avoid an unstable characteristic equation.

</div>
</details>

<details>
<summary>5. Does feedback always increase input resistance?</summary>
<div>

No. Series voltage comparison tends to increase it; shunt current comparison tends to decrease it.

</div>
